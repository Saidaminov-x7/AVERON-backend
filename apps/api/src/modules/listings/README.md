# Listings Module (Legacy / Archival)

> **Статус**: Архивно / Не подключено к публичному роутингу AVERON.

Данный модуль содержит исходную реализацию функционала доски объявлений об аренде недвижимости (Ijarauz):
- Управление объявлениями (`Listing`, `ListingStatus`, `ModerationStatus`)
- Поиск с гео-координатами и фильтрами
- Оценка стоимости аренды AI-моделью
- Жалобы и модерация объявлений

### Почему модуль сохранён:
1. **Prisma Schema**: Модели данных (`Listing`, `ViewingRequest`, `Favorite` и др.) зафиксированы в схеме базы данных PostgreSQL и исторических миграциях. Удаление кода модуля без проведения деструктивной миграции БД может нарушить зависимости в типах `@prisma/client` и существующих внешних ключах.
2. **Административные сервисы**: Часть внутренних утилит `AdminService` и схем валидации исторически ссылается на типы DTO объявлений.

### Интеграция:
- Роут `server.register(listingsModule)` **отключен** в основном файле сервера `apps/api/src/server.ts`.
- Публичный API и витрина AVERON обслуживаются через e-commerce модуль (`/api/v1` — `commerceModule`).
