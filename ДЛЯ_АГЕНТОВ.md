# AVERON Backend — заметки для разработчиков

Backend — Fastify API на TypeScript с Prisma и PostgreSQL. Commerce API
обслуживает витрину и Admin; подробные команды, миграционная политика и
интеграционные статусы описаны в `README.md`.

## Правила изменений

- Проверяйте фактическую регистрацию маршрутов в `apps/api/src/server.ts`.
  Исторические rental-модули и Prisma-модели не являются контрактом storefront.
- Не удаляйте legacy-таблицы и не выполняйте `db push`, reset или destructive
  migration без отдельного согласованного плана и проверки резервных копий.
- Заказы, цены, остатки, скидки, промокоды, shipment state и публикация товара
  должны оставаться server-authoritative.
- Новые интеграции должны быть выключены по умолчанию, явно отражены в
  `/api/v1/capabilities` и Admin diagnostics и сообщать точный статус провайдера.
- Не заявляйте live-поддержку для адаптера без зарегистрированного транспорта,
  конфигурации и подтверждённой проверки провайдера.
- Не помещайте credentials, токены или пользовательские данные в клиентские
  ответы и логи.
- Production-миграции выполняются только через проверенный entrypoint и
  committed Prisma migrations; см. `README.md`.

## Проверки

Из каталога `AVERON_backend`:

```sh
pnpm --filter api build
pnpm --filter api test
pnpm --filter api lint
```

Тесты, которым нужны `DATABASE_URL`, Redis или иные окружения, следует запускать
только в изолированной среде с тестовыми ресурсами.
