# РУКОВОДСТВО ДЛЯ AI-АГЕНТОВ: БЭКЕНД API (IJARAUZ FASTIFY BACKEND)

> **Назначение документа:** Справочник по серверной архитектуре, структуре базы данных PostgreSQL, Prisma-схеме, кэшированию Redis, модулям API, безопасности и тестированию для **ijarauz_backend**.

---

## 1. СТЕК ТЕХНОЛОГИЙ И АРХИТЕКТУРА

- **Серверный фреймворк:** Node.js + Fastify (высокая производительность и малый оверхед).
- **База данных:** PostgreSQL + Prisma ORM.
- **Кэш и очереди:** Redis (ioredis).
- **Аутентификация:** JWT (Access Token в теле ответа / Refresh Token в защищённой `httpOnly` Cookie) + Argon2 хэширование паролей + Google OAuth.
- **Тестирование:** Vitest.
- **Валидация схем:** Zod.

## 3. БАЗА ДАННЫХ И ОСНОВНЫЕ МОДЕЛИ (PRISMA)

1. **`User` / `AdminRole`**:
   - Роли: `USER`, `LANDLORD`, `ADMIN`.
   - Внутренние роли админки (`AdminRole`): `SUPER_ADMIN`, `ADMIN`, `MODERATOR`, `SUPPORT`.
2. **`Listing` / `ListingStatus` / `ModerationStatus`**:
   - Статусы модерации: `PENDING`, `APPROVED`, `REJECTED`, `CHANGES_REQUESTED`.
   - Продвижение (`PromotionTier`): `BASIC`, `TOP`, `URGENT` + поле `promotedUntil`.
   - Верификация: `isVerified`, `verifiedAt`, `verifiedBy`.
3. **`ListingReport` / `ReportReason`**:
   - Причины: `SCAM`, `ALREADY_RENTED`, `WRONG_PRICE`, `WRONG_PHOTOS`, `DUPLICATE`, `REALTOR`, `OTHER`.
4. **`UserActivityLog`**:
   - Логирование действий пользователей (`LOGIN`, `LISTING_CREATED`, `VIEWED` и т.д.) с IP и UserAgent.
5. **`ClientErrorReport`**:
   - Хранение сообщений об ошибках, стектрейсов и URL клиентских сбоев.
6. **`PromoCode`**:
   - Промокоды на скидку (`code`, `discountPercent`, `maxUses`, `usedCount`, `expiresAt`, `isActive`).
7. **`SearchQueryLog`**:
   - Аналитика поисковых запросов пользователей и выявление ненайденного спроса (`resultsCount: 0`).
8. **`SystemWebhook`**:
   - Интеграция с внешними сервисами и Telegram-ботами модераторов.

## 4. КЛЮЧЕВЫЕ СЕРВИСЫ И МОДУЛИ

### 4.1. FraudDetectionService (`modules/admin/fraudDetection.service.ts`)
Вычисляет Fraud Score от 0 до 100 на основе:
- Верификации телефонного номера/профиля автора (+20).
- Возраста аккаунта менее 24 часов (+25).
- Наличия мошеннических триггерных фраз и требований предоплаты на карту (+15..35).
- Отсутствия или недостаточности фотографий (+10..20).
- Аномально заниженной цены относительно медианы района на 35%+ (+30).
- Поиска текстовых дубликатов в базе данных (+25).
- Формирует вердикт справедливой цены: `UNDERPRICED`, `FAIR`, `OVERPRICED`.

### 4.2. Безопасность и Cookie (`lib/cookies.ts`)
- Access Token передаётся в Authorization заголовке (`Bearer <token>`).
- Refresh Token хранится в безопасной `httpOnly` куке с флагами `SameSite: Lax` и `Secure` в production.

## 5. ТЕСТИРОВАНИЕ И ПРОВЕРКА

Перед любым коммитом агент **ОБЯЗАН** выполнить:
```bash
# 1. Генерация Prisma клиента при изменении схемы
pnpm prisma:generate

# 2. Проверка типов TypeScript
pnpm --filter api type-check

# 3. Запуск unit/integration тестов
pnpm --filter api test
```
Все тесты и проверка типов должны завершаться с кодом `0`.
